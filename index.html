MacPocket

An AI voice note-taker for macOS — a software clone of the Pocket AI hardware device. Record a meeting from your microphone or system audio, transcribe it locally with Whisper, and get a summary with action items in seconds.

View on GitHub Get started

Why MacPocket

🎙️

Mic + system audio

Capture your own voice, a Zoom/Meet call via BlackHole, or both — chunked recording keeps memory flat on long meetings.

📝

Local transcription

Runs OpenAI's Whisper entirely on-device. Choose tiny/base/small/medium for your speed–accuracy tradeoff.

🤖

Summary + action items

A 3-bullet summary and a checklist of action items with inferred owners, via Ollama (local) or OpenAI (cloud).

🔒

Private by default

Audio and transcripts never leave your Mac unless you explicitly opt into the OpenAI summarization backend.

Get started

  1. Clone the repo and enter the project folder 
    git clone https://github.com/New-AI-tech/ai-meeting-assistant.git
cd ai-meeting-assistant/macpocket
  2. Run the setup script — installs Homebrew deps (BlackHole, ffmpeg, portaudio) and a Python virtualenv 
    chmod +x setup.sh
./setup.sh
  3. Activate the environment and record your first note 
    source venv/bin/activate
python main.py

Privacy

With the default local backend, audio and transcripts stay on your Mac the entire time. Switching to --backend openai sends only the transcript text (never audio) to OpenAI for summarization. Notes are saved locally to ~/MacPocket/Notes/ — nothing is uploaded or synced anywhere by MacPocket itself.
